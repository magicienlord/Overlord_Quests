# OVERLORD REIGN V5 Authority Closure Register

Status: V5 AUTHORING CONTROL / NON-NARRATIVE INDEX

Date: 2026-09-16

Purpose: prevent earlier supporting audits, older production documents, and superseded UNKNOWN notes from being mistaken for current V5 campaign authority. This register does not create new campaign lore or progression. It records which later authority already closes an older gap and distinguishes remaining authored decisions from technical translation work.

## 1. Authority rule

A supporting audit records what was known when the audit was written.

When a later focused V5 authority explicitly resolves one of its gaps, the focused authority governs. The old audit should remain useful as technical evidence but must not be used to reopen the resolved decision.

Current campaign authority is therefore read in this order inside the V5 branch:

```text
latest explicit Overlord approval
-> focused V5 authority that records that approval
-> aggregate V5 authority
-> supporting technical/source audit
-> older production or assignment documentation
```
