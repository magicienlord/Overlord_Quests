# OVERLORD REIGN V5 Overlord Approval Governance

Status: HIGHEST OPERATIONAL V5 AUTHORING GOVERNANCE

Date: 2026-09-16

Purpose: prevent any current or future author, agent, or implementation pass from treating an unapproved campaign-design choice as V5 authority.

## 1. Absolute approval rule

Only two classes of information may become authoritative in V5:

1. an explicit decision made or explicitly approved by the Overlord;
2. a verified technical fact established directly from the exact installed mod, source, JAR, API, registry, advancement, Questlog framework, or other implementation evidence.

A verified technical fact may establish what is possible, what an identifier is, what native state exists, how a mechanic behaves, or which source signal can be observed. It does not decide how V5 uses that fact.

Every authored campaign choice requires explicit Overlord approval before it becomes authority.

This includes, without limitation:

- campaign scope;
- questline existence or exclusion;
- quest beat count;
- quest beat order;
- prerequisites and unlock relationships;
- exact player-facing objectives;
- exact actions that start or anchor a questline;
- branch structure;
- terminal outcomes;
- persistent consequences;
- presenter assignment;
- presenter theme ownership;
- presenter visual-state vocabulary;
- Rambling inclusion or exclusion;
- which advancement, statistic, item, structure, boss, or native event deserves a Rambling;
- speaker assignment for a Rambling;
- content allocation between Questlog, provider dialogue, native progression, Ramblings, ambient content, or exclusion;
- arc culmination or capstone;
- reward meaning;
- historical interpretation;
- any player-experience rule that is not already explicitly approved.

The phrases `proceed`, `keep going`, `continue`, `come back with questions`, or equivalent instructions authorize investigation, technical verification, drafting of proposals, and audit work. They do not authorize the author to decide unresolved campaign design.

If an authored choice cannot be traced to explicit Overlord approval, its status is `UNKNOWN / REQUIRES OVERLORD DECISION` or `PROPOSAL`, never CANON or authoritative PLANNED content.

## 2. No inference promotion

The following are not approval:

- a mod having an advancement;
- a framework supporting an objective type;
- an older production quest already existing;
- an earlier assistant recommending an option;
- a source mechanic making one route convenient;
- a lore document leaving Quest-Maker discretion;
- an assistant deciding that a choice is minor, obvious, elegant, or low-cost;
- a file being named `AUTHORITY` or `AUTHORED_BLUEPRINT`;
- a choice having already been committed to this branch.

Technical convenience cannot promote a design choice into V5 authority.

## 3. Contamination quarantine

The V5 branch contains mixed documents written before this rule was enforced strictly enough. Some contain explicit Overlord decisions, some verified technical facts, and some assistant-authored choices that were never approved.

Until the provenance audit is complete, every existing V5 file is read clause-by-clause under this rule.

Particular caution applies to:

- `V5_*_AUTHORED_BLUEPRINT.md`;
- `V5_RAMBLINGS_AUTHORITY.md`;
- `V5_PRESENTER_SYSTEM_AUTHORITY.md`;
- `V5_CAMPAIGN_COVERAGE_MASTER_INDEX.md`;
- `V5_AUTHORITY_CLOSURE_REGISTER_2026-09-16.md`;
- aggregate civilization authored graphs;
- objective-authority files that selected exact player actions;
- any document that converted a technical audit directly into a final quest or presentation rule.

Nothing in those files is grandfathered merely because it is already committed.

For each clause, the provenance audit must classify it as:

- `OVERLORD APPROVED`: explicitly approved by the Overlord;
- `VERIFIED TECHNICAL FACT`: source-owned fact only;
- `PROPOSAL`: useful option awaiting approval;
- `UNKNOWN / REQUIRES OVERLORD DECISION`: unresolved authored question;
- `SUPERSEDED`: replaced by a later explicit Overlord decision.

Only the first two classes may be relied on while V5 is being finalized.

## 4. Required review workflow

For every unresolved V5 section:

1. inspect current canon, existing explicit V5 decisions, and exact technical sources;
2. separate technical facts from authored choices;
3. formulate the narrowest meaningful options or proposal;
4. bring every authored choice to the Overlord;
5. record the Overlord's answer;
6. only then promote the approved choice into the final V5 authority;
7. preserve any intentionally UNKNOWN lore as UNKNOWN rather than filling it.

Questions should be grouped coherently when possible, but grouping must never hide individual choices that require approval.
